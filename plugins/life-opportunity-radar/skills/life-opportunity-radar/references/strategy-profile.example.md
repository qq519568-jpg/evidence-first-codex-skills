# Local strategy profile schema

This is an empty schema. Copy it to a private location outside the public repository and fill only the fields you want the skill to use.

```yaml
objective: ""
time_horizon: ""
known_paths: []
excluded_paths: []
evidence_of_strengths: []
constraints:
  capital: UNKNOWN
  time: UNKNOWN
  location: UNKNOWN
  language: UNKNOWN
  social_energy: UNKNOWN
  health_or_physical: UNKNOWN
risk_limits: []
current_bets: []
open_questions: []
last_reviewed: ""
```

Keep confirmed observations separate from self-descriptions and hypotheses. Do not store credentials, exact financial obligations, identity documents, health records, or third-party personal data in this profile.
