# 版权与来源闸门 v1

> 这是保守的生产准入规则，用于降低版权与来源风险，不是法律意见或零风险保证。高价值商业发布、真实人物/品牌或权利链复杂的资产应交专业律师复核。

## 目录

- 一票否决与允许级别
- C0—C7准入、许可策略与采购范围
- 证据包、状态机与外部包安全
- 发布前版权包

## 一票否决原则

“免费下载”“royalty-free”“可在预览器里看到”“搜索结果写 CC0”“AI 说能用”都不是许可证据。没有逐资产、可追溯、可存档的许可原文，就标 `HOLD_LICENSE`。

以下任何一项成立，禁止进入生产：

- 来源页、作者/发布主体或下载包对应关系不清；
- 许可只存在于转载者描述、评论、搜索摘要或模型口头结论；
- `NC`、`ND`、Editorial、Personal use only、教育用途限定；
- 禁止修改、禁止商业使用、禁止渲染成片，或条款互相冲突；
- 影视/游戏拆包、fan model、盗版/破解包、明显仿制受保护角色或标志性道具；
- 许可要求本管线无法履行，或条款要求把项目/资产以不接受的方式再授权；
- 商标、肖像、隐私、专利或第三方素材权利明显不明；
- 网页已失效且没有足够的原始证据包。

## 允许级别

| 级别 | 默认处理 | 必须满足 |
|---|---|---|
| `GREEN_SELF` | 可准入 | 自制/委托文件，权属与授权书存档 |
| `GREEN_CC0` | 优先准入 | 官方作者页逐资产标 CC0；许可页、作者、日期、原包、哈希均存档 |
| `GREEN_CCBY` | 条件准入 | CC BY 明确允许商业使用与修改；署名文本、原链接、许可链接、修改说明可随项目交付 |
| `GREEN_COMMERCIAL` | 条件准入 | 购买凭证、当日条款、账号/主体、席位、项目和再分发限制全部存档并适配本用途 |
| `HOLD_LICENSE` | 阻断 | 任一证据或权利字段未知，等待人工/法律确认 |
| `REJECTED` | 禁用 | 明确不符合、侵权迹象、禁用条款或来源不可信 |

只有资产清单 `status=APPROVED` 才能进入 Blender 生产。`GREEN_*` 是版权判断；仍需技术与视觉验收后才可 `APPROVED`。

## C0–C7 准入闸门

| Gate | 检查 | 通过证据 |
|---|---|---|
| C0 需求 | 先有明确 Shot 缺口 | `asset_request.yaml`，含用途、景别、精度、替代与禁项 |
| C1 来源 | 找到第一发布者/官方资产页 | 原始 URL、作者/主体、资产名、访问日期 |
| C2 许可 | 许可明确对应这项资产 | 许可代码、许可 URL、页面/文本快照；不能只存站点总条款 |
| C3 权利用途 | 商业使用、修改、渲染输出均允许 | 三项分别为 `true`，未知不是通过 |
| C4 义务 | 署名、修改声明、通知、席位等可履行 | 完整 attribution 文本或购买/授权记录 |
| C5 第三方权利 | 无明显 IP/商标/肖像/隐私冲突 | 人工检查记录；有疑问即 HOLD |
| C6 固化 | 下载物与证据不可混淆 | 原包、SHA-256、证据文件、访问日期同目录保存 |
| C7 双验收 | 技术健康且导演看得懂 | `REVIEW_TECH` → `REVIEW_VISUAL` → `APPROVED` |

## 许可默认策略

- **默认自动候选**：`CC0-1.0`、权利明确的公有领域工具、自制/委托且书面权利完整。
- **需履约后候选**：`CC-BY-4.0`；必须保留作者、标题（如提供）、来源 URL、许可 URL、修改说明，不暗示作者背书。
- **默认拒绝**：任何 `NC`、`ND`、Editorial、Personal、Research/Education-only，以及无明确许可代码的“free/royalty-free”。
- **付费许可**：禁止 agent 自行购买、登录、勾选条款或代表用户接受协议；必须由用户明确授权并保存发票与当日条款。
- **站点白名单不等于资产白名单**：每个资产仍逐项核验。

## 范围化采购

资产需求卡必须先于开放搜索，至少写：Shot ID与动作结果；资产角色；景别和屏占比；三项身份线索；绑定、握持、接触、破坏或开合需求；最低L1/L2/L3与技术预算；可接受替代和禁项；商业使用、修改、渲染输出及署名要求。没有需求卡，不批量下载。

优先顺序：

| 优先级 | 范围 | 适用 | 暂不主攻 |
|---|---|---|---|
| P0 | 标准骨架人形代理、真实握把武器、短动作模块、模块化场景 | 1—2个主体、2—4秒单结果、中近景一次接触 | 名角复刻、脸部特写、复杂毛发/布料 |
| P1 | 可拆环境组合、24/35/50/85mm机位、平光审片、VFX中性代理 | 走位、遮挡、首帧同构和时机占位 | 拥挤城市、群体交通、真实流体与爆炸 |
| P2 | 中性粘土、语义审片色和基础材质 | 识别与预览 | 最终写实材质库 |

只有能减少建模、沟通或试错成本的资产才入库。禁止因“以后可能有用”下载，也禁止以资产库存量替代镜头风险判断。

## 证据包结构

每个来源包独立目录：

```text
80_SourcePackages_原始下载包/<Source_Package_ID>/
├─ Original_Files/             # 原始包，不覆盖
├─ LICENSE.txt或LICENSE.pdf     # 发布者提供的许可
├─ source_page.*               # 页面截图/PDF/HTML，能看到资产与许可对应
├─ 来源说明.md                  # URL、作者、访问日期、用途、判断
├─ attribution.txt             # 需要署名时必有
└─ SHA256SUMS.txt               # 原包和关键源文件哈希
```

网页证据至少包含：资产名、发布者、许可名称/链接、下载对应关系和访问日期。页面变化后，已存证版本不自动失效，但发布前应重新检查是否有权利争议或撤回通知。

## 状态机

```text
REQUESTED → SOURCE_REVIEW → HOLD_LICENSE / REJECTED
                         ↘ INBOX → REVIEW_TECH → REVIEW_VISUAL → APPROVED
APPROVED 发生许可争议 → QUARANTINED → 重新核验或 REJECTED
```

- `INBOX` 只允许隔离检查，不能进入镜头生产；
- `REVIEW_TECH`、`REVIEW_VISUAL` 只是候选；
- `APPROVED` 必须同时有版权、技术、视觉签字；
- 许可证据丢失、来源被质疑或文件哈希改变，自动降为 `QUARANTINED`。

## 外部包安全边界

- 下载到隔离目录，不运行附带 `.exe`、脚本、宏或 Blender 插件；
- `.blend` 打开时禁用自动执行脚本，外链文件先盘点；
- 不把未审查的启动文件、Python、驱动表达式或插件复制进正式库；
- 原包保持只读思路，清洗副本另存并记录修改。

## 发布前版权包

项目交付至少生成：

- 本项目使用的全部 `Asset_ID`；
- 每项许可代码、作者、来源、证据路径、哈希；
- 所需署名与修改说明；
- `HOLD/REJECTED/QUARANTINED` 为零；
- 商标/肖像/第三方 IP 人工复核结论。
