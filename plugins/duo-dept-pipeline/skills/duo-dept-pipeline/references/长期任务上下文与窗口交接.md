# 长期任务上下文与自动窗口交接

## 原则

- 剧情讨论是长期主线；Blender、DeepSeek、QA、供应商排查和技能维护是可重建的单次执行任务。
- 原始信息不靠聊天记忆保存，而靠项目真相板、执行状态与证据索引保存。聊天只负责本轮判断和差量沟通。
- 自动换任务发生在消息轮次边界或阶段边界；当前没有可靠的实时上下文百分比接口，不得声称能后台精确监测token占比。

## 项目上下文文件

长期项目在正式项目根维护：

1. `00_项目核心.md`：长期世界观、权威边界和通用约束，少改。
2. `<场次>_导演真相板.md`：唯一创作正本，按剧情卡保存秒数、空间、动机、并行动作、接触、即时反馈、下一因果和Unknown。
3. `<场次>_执行状态.json`：实际`.blend`、帧段、技术QA和导演验收状态。
4. `<场次>_证据索引.md`：原始材料、报告、图片、脚本和QA的路径、角色与状态。
5. `<场次>_当前交接.md`：不超过40行的热路由，只写当前范围、锁定卡、文件版本、唯一下一步和禁止事项。
6. `<场次>_决策日志.md`：追加保存重要“旧→新”、原因和影响卡；默认不加载。

不得维护两个手工创作正本。当前交接是从真相板与执行状态抽取的路由页，不得反过来覆盖真相板。

## 状态词

- `PROPOSED`：专业建议，导演尚未确认。
- `LOCKED`：导演已确认，可进入执行。
- `UNKNOWN`：尚未确定。
- `REJECTED`：明确废弃，不得因旧聊天或旧候选恢复。
- `EXECUTED`：已写入候选工程。
- `QA_PASS`：技术验证通过。
- `DIRECTOR_PASS`：导演语义验收通过。

`QA_PASS`永远不等于`DIRECTOR_PASS`。

## 导演室更新

- 用户每次修订只更新受影响剧情卡，并追加一条重要决策日志；普通措辞润色不记日志。
- 回复只展示：导演意图理解、旧→新、前置条件、对后续卡的影响、剩余Unknown。
- 一组剧情卡锁定前不换算帧数、不修改Blender。锁定后由执行状态记录秒数到帧号的映射。
- 项目剧情不得写进全局技能；只有跨项目可复现的工作法才进入技能变更队列。

## 自动交接判断

用户已对电影预演长期工作流给予持续授权：命中安全交接条件时，可自动创建新Codex任务，无需再次请求“开新窗口”。每轮开始和结束检查以下信号。

### 立即交接

- 当前任务出现可见compaction，且下一步不是一句话即可完成。
- 继续工作需要重新翻旧聊天才能确定剧情真相。
- 出现`systemError`、持续`Bad Request`或任务路由状态可疑。
- `PRODUCTION`即将转入独立且较长的Blender、DeepSeek或综合QA任务，继续留在原任务会挤压导演真相。
- 生产任务需要插入独立的技能、凭据、平台或Codex故障维护。

### 自然边界交接

- 一组完整剧情卡已经`LOCKED`。
- 新`.blend`版本与技术QA已完成，下一步回到导演判断。
- 工作范围从前段切到中段、山君段或后续自爆/请神段。
- 当前任务活动材料将超过“技能+当前交接+1份任务参考”。
- 已产生大量工具输出，但下一步只需要其结论和证据路径。

### 评分辅助

无法看到精确上下文比例时使用评分：

- 3分：首次compaction、系统错误、必须回读旧聊天、用户指出遗忘。
- 2分：阶段切换、一个版本完成、8个以上实质工作轮次、活动材料超过预算。
- 1分：3张以上剧情卡锁定、出现两个以上不相关任务类型、一次回复需要复述大段历史。

总分达到3且当前外部操作已安全落盘时，自动交接。`EXPLORE`中的导演室/执行室切换不单独触发新任务；先保持短闭环，只有材料超预算或独立长任务能提高效率时才交接。

## 自动新任务步骤

1. 将导演最新口述写回真相板，明确`LOCKED/PROPOSED/UNKNOWN/REJECTED`。
2. 回读实际文件，更新执行状态；不能用计划冒充已执行。
3. 验证证据索引中的当前文件路径；敏感凭据只记地址和用途，不记值。
4. 生成或覆盖不超过40行的当前交接，写清唯一下一步和禁止事项。
5. 若任务工具可用，创建对应的新Codex任务：
   - 导演继任任务：只读技能、当前交接和选中剧情卡。
   - 执行任务：再加1份执行参考；DeepSeek/子代理只按ROI与独立复核需要调用。
   - 维护任务：不加载剧情正文，只读技能正本和维护证据。
6. 等待新任务实际开始并报告任务链接；创建失败则留在原任务，输出同样的可复制启动语。
7. 原任务冻结，不继续扩写；不要自动归档，除非导演明确要求。

## 子代理与执行输出

- 子代理和DeepSeek均从精简文件启动，不复制导演室历史。
- 完整分析写入各自文件；返回父任务只包含结论、证据路径、冲突和Unknown。
- 任何代理不得更新导演真相板；只有导演室主任务可写创作正本。
- 任何代理不得同时修改同一正式脚本、YAML或`.blend`；Codex主执行端唯一合并。

## 故障恢复

- 自动换任务不能发生在未保存Blender、未完成外部写入或无法确定输出状态时。先安全落盘并记录状态。
- 新任务失败不代表交接文件错误；检查任务状态和应用日志，再决定是否重建。
- “清理上下文”默认不删除工程、报告或旧任务，只冻结交接并从最小读取集恢复。
