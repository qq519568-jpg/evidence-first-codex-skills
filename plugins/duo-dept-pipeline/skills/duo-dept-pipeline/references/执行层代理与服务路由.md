# 执行层代理与服务路由

## 目标

把DeepSeek和Codex子代理用于可隔离、可复核的执行分析；导演剧情真相始终由Codex主任务与导演真相板持有。多代理增加总计算与token，不得宣称免费；它们的完整过程不进入导演任务上下文。

调用Codex子代理前先按`references/自动性能路由_模型与推理强度.md`选择模型与推理强度；DeepSeek是否调用仍按本文件判定，两套路由不得互相替代。

## ROI调用规则

- `EXPLORE`默认不并行多代理：一个执行器负责产出，本地确定性脚本负责结构、轨迹、跳变和文件QA。普通Blender站位、速度、曲线和已锁动作修订不得仅因“非琐碎”自动调用DeepSeek。
- 只有满足至少一项才调用代理：独立并行能缩短墙钟时间；人体/四足力学确有Unknown；脚本或证据冲突；准备锁定、晋升或发布；代理结果能形成可复用能力而非重复报告。
- 同类导演问题连续两次、15—20分钟无新可见成果、AI预计比导演手动慢三倍时，停止代理扩张，优先交给导演、安装桥接、购买成熟工具或考虑熟练人工。
- 需要多路时按任务选择，不默认全开：
  1. 动作力学：准备、发力链、接触、惯性、受击与恢复。
  2. 空间连续：方向、遮挡、攻击条件、并行动作与角色路线。
  3. Blender实施：骨架、关键帧、约束、插值、对象层级与可复现脚本。
  4. 技术QA：穿插、跳变、迟滞、文件状态、帧段和可重复验证。
  5. 导演可读性：观众能否读懂意图、力量、速度和动作后果。
- 单对象坐标修复、静态误关键帧清理、已验证脚本原样复跑、单一格式转换和导演已确认的整段位置传播均使用单执行器。
- 每个执行任务只做一次不计费`/models`健康检查；同一任务内不要为每个分段重复探活。
- `EXPLORE`报告只写结论、可见结果、耗时、失败停止条件和Unknown；仅`PRODUCTION`或复杂复审使用完整结构并落盘。
- Codex主执行端只把被证据支持的结论写入正式脚本；不同DeepSeek意见冲突时明报，不用投票代替判断。

## DeepSeek连接优先级

1. DeepSeek官方：`https://api.deepseek.com/v1`
2. OpenCode Go：`https://opencode.ai/zen/go/v1`
3. API易：`https://api.apiyi.com/v1`

三路均曾实测可列出`deepseek-v4-pro`。优先API直连并发。OpenCode CLI仅在需要会话状态、文件代理或工具循环时使用：

用`Get-Command opencode -ErrorAction SilentlyContinue`解析本机入口；找不到时报告缺失，不猜测用户目录。

普通`PATH`找不到时先检查固定路径；网页登录不得静默替代；OpenCode不使用`--auto`。仅有网页/PWA、Ollama进程但无对应模型和API端点，不算可调用本地DeepSeek执行端。

## 凭据边界

- 混合CSV可能把服务说明、网址和Key整段放进`Username`单元格；必须逐行按标签识别，不能只看标准表头。
- `DeepSeek / OPENCODE GO / APIYI`属于DeepSeek推理链。
- `腾讯云用户名/密码/登录地址 + CAM SecretId/SecretKey + 混元3D Key`属于混元3D账号、官方API和模型资产生成链。
- 不得跨供应商试探凭据。CSV、API密钥、CAM凭据、登录口令和`.blend`不得作为外部模型附件；日志只记供应商、模型、耗时和脱敏错误。

## Codex子代理

- 子代理适合：独立材料读取、动作力学复核、脚本审查、结构数据分析、图像/QA检查。
- 使用最小上下文分叉；优先不给旧聊天，只传：剧情卡ID、精简交接、文件路径、输出格式、禁止事项和停止条件。
- 子代理拥有独立工作上下文；主任务只接收必要结果，因此不会自动把其全部过程灌入导演上下文。但子代理本身仍产生额外总token与运行成本。
- 子代理可共享项目文件，但不得同时修改同一脚本、YAML或`.blend`。每路只写独立报告或独占输出路径。
- 导演真相、候选/锁定裁决、正式合并、Blender运行与最终QA均由Codex主执行端负责。
- 探索期一次性代理输出不强制落盘；只有可复用脚本、能力结论、正式复审证据才保存。回传主任务只保留结论、冲突和Unknown。

## 混元3D

- `scripts/hunyuan3d_client.py`是正式API执行端；项目闸门为`REQUIRED`且CAM凭据可解析时，默认直接提交、轮询、下载、哈希和回写，不再做独立预检或重复费用确认。
- 预演代理默认Rapid；英雄/正式资产默认Pro 3.1；每个闸门1次生成及最多1次证据驱动重试。完整状态和产物留在项目，不灌回导演上下文。
- 当前官方对象/后处理API不等于3D世界本体。仅产品界面有世界能力时，Codex交一条不超过600字提示词与导出清单；正式世界API工具真实出现时自动调用。
- 凭据缺失、权限/配额错误、输入语义未锁或外部IP不清时写`BLOCKED`；不得转用网页私有接口。详细规则与历史证据见`references/混元3D世界_导演生成交接.md`。
