# 经验沉淀最小协议

只记录能减少未来重复劳动的经验，不记录单次任务过程、调用次数、端口、会话、派单、成功回执或完整聊天。

## 写入条件

同时满足才写：

1. 不是项目特例；
2. 有明确症状和根因；
3. 修复已实际验证；
4. 能变成规则、断言、脚本或检索关键词。

## 最小字段

```yaml
title: 一句话经验
scope: BLENDER_GENERAL | PIPELINE_GENERAL | MODEL_SPECIFIC
symptom: 可观察失败
root_cause: 已验证根因
fix: 最短可靠做法
evidence: 最小复现或文件路径
validation: 验证命令与结果
search_terms: [以后能搜到它的关键词]
```

优先级：修脚本/加断言 > 更新对应reference > 修改常驻铁律。证据不足就不晋升；同义经验合并，不新增重复段落。每次新增常驻规则必须同时合并或下沉一条旧规则。
