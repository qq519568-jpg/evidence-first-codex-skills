# 混元3D强制资产闸门与API自动化

## 强制判定

每个项目初始化、剧情段转`LOCKED`、新版本开工、资产库检索结束或下游需要正式资产时，更新项目`01_项目总档案/00_上下文/混元3D_资产闸门.json`。

- `NOT_EVALUATED`：尚未判断，不得进入正式资产制作。
- `NOT_NEEDED`：现有批准资产满足当前锁定语义；必须写具体理由和资产路径。
- `REQUIRED`：已锁语义确实缺少世界、角色、怪物、道具、动作或后处理结果。
- `UI_HANDOFF`：只有产品界面能完成3D世界本体，等待导演生成和导出。
- `SUBMITTED/WAITING/RETURNED/QA_PASS/BLOCKED`：由客户端或QA回写。

`REQUIRED`必须同时满足：`semantic_lock=LOCKED`、资产库结果为`MISSING`、`copyright_decision=ALLOW_SELF/ALLOW_LICENSED`、请求只生成一个有`asset_id`的明确资产、输出目录已指定。客户端会机械复核这些字段，不只相信Agent判断。满足后只要正式客户端和CAM凭据可用，立即调用；不再拆出能力预检或常规费用确认。每个闸门允许1次生成和最多1次有`retry_evidence`的修订重试，禁止无差别多变体。

“动作资产”只指独立可交付的文生动作或动作文件；对既有批准角色修改Blender关键帧不属于资产缺口，写有理由的`NOT_NEEDED`。

## 当前官方基线（核对日期：2026-08-16）

- 中国站域名：`ai3d.tencentcloudapi.com`；服务名：`ai3d`；版本：`2025-05-13`；默认地域：`ap-guangzhou`。
- 专业版：`SubmitHunyuanTo3DProJob` → `QueryHunyuanTo3DProJob`，支持模型3.0/3.1、Normal/LowPoly/Geometry/Sketch、PBR、面数和格式等参数。
- 极速版：`SubmitHunyuanTo3DRapidJob` → `QueryHunyuanTo3DRapidJob`。
- 状态：`WAIT/RUN/FAIL/DONE`；JobId与结果下载URL有效期均短，`DONE`后必须立即下载和哈希。
- 官方后处理动作白名单由客户端固定：纹理、拓扑、组件、UV、文生动作、绑骨蒙皮、3D人物和格式转换；接口变化时先复核腾讯云正式文档再改脚本。

默认选择：预演、替身、轮廓验证用Rapid；英雄、正式近景或质量优先资产用Pro 3.1 Normal。只有需求明确时才加PBR、FaceCount或ResultFormat，避免无收益积分叠加。常规调用已获持续授权；超出单资产加一次修订、多变体批量或异常附加费用仍需暂停。

## 执行命令

资产闸门自动执行：

```powershell
python scripts/hunyuan3d_client.py gate-run --gate-file "<项目上下文>\混元3D_资产闸门.json"
```

`gate-run`是项目正式资产生成的唯一入口；下面的`run`只用于维护烟测或无项目闸门的旧任务恢复，不得绕过闸门用于生产项目。

维护烟测直接生成：

```powershell
python scripts/hunyuan3d_client.py run --edition rapid --prompt "<已锁定资产提示词>" --output-dir "<项目回传目录>"
python scripts/hunyuan3d_client.py run --edition pro --model 3.1 --generate-type Normal --prompt "<已锁定资产提示词>" --output-dir "<项目回传目录>"
```

中断恢复：

```powershell
python scripts/hunyuan3d_client.py resume --edition rapid --job-id "<JobId>" --output-dir "<原输出目录>" --gate-file "<资产闸门>"
```

其他官方动作使用`invoke --action <白名单动作> --params-file <JSON> --output-dir <目录> --wait`。先运行`self-test`验证本地签名、凭据解析和脱敏逻辑；这不是每次项目调用前的网络预检。

## 凭据与安全

客户端按顺序读取显式`--credential-csv`、环境变量`TENCENTCLOUD_SECRET_ID/TENCENTCLOUD_SECRET_KEY`、`HUNYUAN3D_CREDENTIAL_CSV`，最后检查用户桌面的`新建子用户信息.csv`。仅使用同一行标准CAM `SecretId/SecretKey`；混元产品Key、网页登录口令和DeepSeek Key均不能用于腾讯云API 3.0签名。

密钥不写入请求清单、技能、提示词、报告或日志。输出只保留凭据来源路径、JobId、RequestId、状态、实际积分、脱敏下载源、文件大小和SHA-256。签名URL去除查询参数后才落盘；下载仅允许腾讯COS HTTPS域名。

## 输出与恢复

每个运行目录保存`hunyuan3d_job.json`和下载产物。提交后立即写JobId；WAIT/RUN持续原子更新；DONE下载模型与预览并写哈希；FAIL或异常写脱敏错误。轮询超时不重新提交，用`resume`继续，防止重复扣费。

生成返回不等于资产准入。完成后依次检查：包完整性、格式、解压安全、几何/贴图/骨架、Blender导入、比例与朝向、剧情功能、导演可读性；通过才把闸门写`QA_PASS`并进入资产库或正式项目。

## 3D世界边界

当前官方API列表覆盖对象生成和多类后处理，但未把产品界面的3D世界本体作为上述中国站API动作。若本轮只有产品界面世界能力，闸门写`UI_HANDOFF`，Codex交一条不超过600字的中文提示词和导出清单：`Gaussian PLY`、`SPZ`、`Collider PLY/网格`、`360° Panorama`，界面有哪个就导出哪个；不得误调对象API替代世界。若未来正式世界API或受支持工具真实出现，按同一闸门默认自动调用；不得使用网页私有或逆向接口。

## 历史成功证据

历史成功回传只能证明当时的返回格式与Blender导入链路。公共技能不携带维护者的原始回传路径或私人项目证据；当前API权限、配额、模型版本和新任务状态必须重新核验。
