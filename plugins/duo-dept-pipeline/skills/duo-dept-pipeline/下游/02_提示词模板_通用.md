# 提示词模板 v4（短提示、单主控）

> 只填写当前产品界面真正支持的输入。未验证附件不要在文案中伪装成控制通道。

## 硬规格双写闸门

画幅比例、目标时长、镜头数量/切镜许可、音频开关和目标分辨率必须同时写在“生成前记录”和提示词正文第一句。即使界面已有控件也不得删除提示词中的规格；画布模式没有可选时长或比例窗口时，更必须依靠正文显式声明。界面值与正文冲突时禁止生成。

生成后不得根据文件名或界面标称签收。必须读取实际宽高、fps、帧数和容器时长，并另查关键动作是否落在要求的秒级锚点。总时长正确但动作挤在前半或后半，仍属于时序失败。

## 生成前记录（不一定投喂）

```text
模型/档位：<填>
画幅/目标时长：<填；例如 16:9 / exactly 5 seconds>
镜头/切镜：<单镜头；禁止切镜，或明确允许的镜头数>
音频：<关闭/开启及内容边界>
目标分辨率：<填；无界面选项也要记录目标>
主控制入口：<填，只能一个>
首帧入口：<有/无；必须同构>
能力证据等级：<A/B>
来源 Shot：<SOURCE_TRUTH_vN / Shot ID>
本轮费用与候选数：<填>
参考图职责：<人物图管什么；氛围图管什么；各自禁止控制什么>
外观合同：<downstream_prompt_visual_spec.yaml 路径>
```

## 中文提示词

```text
输出严格为<画幅>，总时长严格为<时长>，<单镜头或明确镜头数与切镜许可>，<音频开关>，目标分辨率<填>。关键动作时间锚点：<0-X秒开始状态；X-Y秒主要动作；Y-结尾结果与稳定状态>。

主体：<角色身份线索三项>，手持<明确武器>。
主要动作：<谁>用<什么>对<谁>做<一个动作>，从<开始状态>到<结果状态>。
方向与接触：<运动方向>；接触发生在<部位>；受击者向<方向>反馈。
镜头：<机位、景别、允许的简单运动>。
外观：角色固有色<主/辅/强调>；环境色<填>；影调<填>；空气/天气<填>；材质观感<填>；成像质地<填>；情绪轴<最重要的2-3项>。
参考职责：人物参考只控制<身份/固有色/表面>；氛围参考只控制<环境/光影观感/空气/情绪>。
禁止新增：<本段来源不存在的角色、武器、爆炸、能量、切镜或后续事件>。
```

## English prompt

```text
Output strictly in <aspect ratio>, with a total duration of exactly <duration>, <one continuous shot or explicit shot count/cut permission>, <audio on/off>, target resolution <value>. Timing anchors: <0-Xs start state; X-Ys primary action; Y-end result and hold>.

Subject: <three stable identity cues>, holding <explicit weapon type>.
Primary action: <who> uses <tool> on <target>, moving from <start state> to <result state>.
Direction and contact: <motion direction>; contact at <body/prop point>; target reacts toward <direction>.
Camera: <view, shot size, simple allowed motion>.
Look: <character local colors>; <environment palette>; <tone>; <atmosphere/weather>; <surface appearance>; <image texture>; <2-3 primary mood axes>.
Reference roles: character reference controls <identity/local color/surface>; atmosphere reference controls <environment/lighting appearance/air/mood>.
Do not add: <characters, weapons, explosions, energy effects, cuts or later events absent from this shot>.
```

## 可选方案回执

若下游支持对话，可先要求它复述“主体、武器、一个主要动作、结果、镜头、禁止新增”。回执不作为能力证明；即使复述正确，仍必须靠小样验收。

## 禁止写法

- “100%严格遵循、逐帧绝对锁死、N帧完全静止”作为能力声明；
- 同时要求视频控制姿态、另一张图控制第一帧，但两者构图不同；
- 把 Depth/ColorMask 文件名、权重写进提示词，界面却没有对应入口；
- 一条 10 秒提示同时塞推进、抓取、劈砍、旋转、投掷、爆炸和多次换机位；
- 用长篇 Negative 代替正向动作设计。
- 把两张参考图的主色直接平均，或让氛围图覆盖角色身份色；
- 把 Hex、色温和情绪分数写成生成模型必然精确执行的承诺；
- 把完整测量表全部塞进自然语言提示词；清单用于编译提示词和验收，不等于每个字段都要投喂。
- 只在设置页填写“5秒/16:9”，却从提示词正文省略时长、比例和单镜头规格；画布模式没有规格控件时尤其禁止省略。
- 只验收导出文件约为5秒，却不检查主要动作是否按秒级锚点发生。
