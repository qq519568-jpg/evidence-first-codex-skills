# 紫微专业详批交付规范

本规范用于用户明确要求紫微“详批、收费级、完整交付”时。专业不等于把十二宫平均写满，而是让口头总断、宫位事实、组合规则、反证、大限边界和现实建议能逐条回查。

> 紫微斗数属于传统文化解释，不是科学预测。报告的完成度只证明推演过程透明，不证明真人经历或未来事件准确。

## 一、双层交付

先执行 [ziwei-client-voice.md](ziwei-client-voice.md)，完成 600–1200 字老师傅总断、三至五个核验点和不符时的排查入口；之后才进入专业证据层。开头关键判断依次标为 `紫断 1`、`紫断 2`……，后文章节逐条回指。

专业证据层达到以下十二项门槛；缺项写 `INCOMPLETE`、`UNKNOWN` 或 `NOT_COMPUTED`：

1. **老师傅总断**：命身、命财官迁、事业/财务、关系或阶段主题中选三至五条最强主线；优势与代价成对出现。
2. **输入与引擎封面**：公历、当地民用时间、时辰序号、地点、时区、性别参数、换日口径、紫微引擎与版本。
3. **命身事实**：命宫/身宫地支、身宫实际落宫、五行局、命主、身主；身宫落宫须从十二宫事实定位。
4. **命宫组合审计**：主星组合、亮度、四化、辅星与杂曜逐项修正；禁止拆成单星词典堆砌。
5. **命财官迁四宫表**：四宫主星、亮度、四化与重要辅煞齐列，再写联动结论和反证。
6. **生年四化表**：逐条引用“星曜→宫位”，解释作用方向；禄权科忌不得直接等同财富、职位、名声或灾祸。
7. **重点主题**：事业、财务、关系、福德各用“人话小结→事实→行话→反证→核验→建议”；健康仅在用户要求时写。
8. **空宫与借宫审计**：点名空宫、对宫、借入主星和降级原因；不得把借星写成本宫直接坐守。
9. **辅煞修正**：吉曜只作支持条件，煞曜只作阻力或棱角；任何单曜都不足以写真人经历。
10. **大限时间轴**：十二宫已有大限区间完整列出；当前/下一限要声明虚岁定位方法，只写阶段主题。
11. **流年边界**：`紫微._meta.流年数据 = NOT_COMPUTED` 时不得手排逐年宫位、四化或事件。
12. **紫断—证据地图**：每条紫断至少有两项事实、一个规则 ID、一个反证、一个现实核验和不确定度。

## 二、证据层级

- **S 级事实**：JSON 直接输出的命身宫、宫位、星曜、亮度、四化和大限区间。
- **A/B 级结构解释**：命身合看、命财官迁联动、四化组合；必须列完整参与宫位。
- **C/D 级现实翻译**：把结构翻译成性格、事业、财务或关系机制；必须可否证。
- **E 级流派解释**：空宫借宫、组合格名等；声明流派与竞争解释。

这些等级表示推演距离，不是科学证据强度或命中概率。

## 三、命财官迁审计表

| 宫位 | 必列事实 | 要回答的问题 |
|---|---|---|
| 命宫 | 主星组合、亮度、四化、辅煞 | 内在驱动与决策方式有哪些相互制约？ |
| 财帛 | 主星组合、亮度、四化、辅煞 | 传统上更强调何种资源交换方式？哪些现实数据无法由命盘得出？ |
| 官禄 | 主星组合、亮度、四化、辅煞 | 更适合何种责任与生产机制？不能直接列固定职业。 |
| 迁移 | 主星组合、亮度、四化、辅煞 | 外部环境、公开协作或跨边界场景如何修正命宫？不等于必须离乡。 |

只有四宫全部核对后，才可谈所谓格局或发展方式。任何宫位为空、亮度缺失或关键字段异常，都要降低结论。

## 四、四化写法

每条按以下顺序：

```text
事实：哪颗星、什么四化、落哪一宫、星曜亮度原值。
人话：该主题为什么更容易获得关注、责任、可见度或反复牵挂。
限制：同宫星曜、亮度、辅煞与对宫怎样修正。
禁止结论：不能从这一条直接推出真实财富、职位、婚育、疾病或具体事件。
```

四化合看时允许指出资源如何在事业、财务、命宫或其他主题之间流动，但不得把“禄权科齐”写成身份等级或成功保证。

## 五、大限与当前阶段

1. 大限区间只能引用脚本的 `十二宫[].大限`。
2. 若报告根据当前公历年计算虚岁，写明公式、`as_of` 年份和这不是脚本单独输出的当前限字段。
3. 宫名表示阶段关注主题，不等于事件：田宅可包括空间、基础、资产安排、家庭边界或内在安顿，不等于必买房。
4. 当前限与下一限可以详写，但必须同时列支持和反向因素。
5. 大限不能替代流年；没有确定性流年输出时不得给具体年份应事。

## 六、交付前自检

- [ ] 开头先讲人话，没有从十二宫表、星曜组合或格局名起笔。
- [ ] 每条紫断至少连接两项盘面事实，并有反证和现实核验。
- [ ] 身宫落宫已从十二宫定位，没有把地支名称当宫名。
- [ ] 命财官迁四宫齐列，未由单星直接定职业、财富或阶层。
- [ ] 四化与亮度引用本次 JSON 原值，不熟悉的亮度缩写没有擅自扩写。
- [ ] 空宫借对宫明确标注为传统推演，且不确定度已提高。
- [ ] 当前大限写明虚岁定位口径，大限主题没有写成具体事件。
- [ ] 紫微流年未计算时保持 `NOT_COMPUTED`。
- [ ] 已知经历或商业背景已标记信息污染，没有包装成盲测命中。
- [ ] 结尾保留传统文化、隐私和高风险决策边界。
