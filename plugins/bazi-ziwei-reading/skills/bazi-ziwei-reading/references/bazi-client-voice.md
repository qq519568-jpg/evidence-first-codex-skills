# 客户向“老师傅口吻”与双层报告规范

本规范只解决一件事：让非行内读者先听懂整体判断，再决定是否查看专业推导。它不授权夸张、恐吓、伪造经历或用万能句制造“很准”的错觉。

## 一、报告采用双层阅读

### 第一层：老师傅先断

详批开头先用约 600–1200 个中文字，把整张盘的主线说成人话。不要从四柱表、五行数、格局名或规则 ID 开始。

开头必须完成五件事：

1. **一句话定主线**：指出这张盘最鲜明的内在矛盾或做事机制，不贴空泛人格标签。
2. **先断三至五条**：覆盖能力/做事方式、事业或财务机制、关系或压力反应；没有充分依据的主题明确说“这条我不硬断”。
3. **好处和难处成对出现**：每个优势紧跟它的代价，避免只说好听话。
4. **给可观察的核验点**：至少三条能被现实行为否证的问题，不先向用户索取经历再改答案。
5. **说明错了从哪里查**：若核心核验点多数不符，先复核出生时间、民用时/真太阳时口径、换日与传统推演分歧；不得在后文不断加解释把所有结果都圆回来。

推荐语感：直接、镇定、像当面细谈；短句多于长句；先说结论，再解释条件。可以自然使用这些句式，但不要机械套模板：

- “我先不跟你堆术语，先把这张盘最要紧的地方说透。”
- “你这盘不是……，真正的问题在……”
- “好处是……；难处也在同一个地方……”
- “这件事做对了是……，做过头就会变成……”
- “这一条我只断到这里，再往下就没有足够依据了。”

禁止用作钩子：

- “准到可怕”“天选之人”“注定大富大贵”等煽动句。
- “外冷内热、重感情、嘴硬心软、想得多”等几乎人人都能对号入座的单独判断。
- 未经用户提供便虚构童年、家庭、婚史、疾病、资产或具体事件。
- 把用户刚说过的经历改写成命盘结论，却不标注信息污染。
- 为了显得果断而省略条件、反证和不确定性。

### 第二层：为什么这样断

第一层的关键判断依次标为 `总断 1`、`总断 2`……。后文每个专业章节在标题下标明它证明或修正哪条总断，形成可回查链路：

```text
总断 2｜适合把复杂问题整理成可交付的方法，但容易准备过度

盘面事实：精确引用本次 chart JSON 字段。
行话解释：说明月令、十神、格局、冲合或岁运规则怎样推出该倾向。
反证与限制：列最强的不支持因素，以及什么情况会推翻或下调判断。
现实核验：给一个能观察、能回答“不符合”的行为问题。
现实建议：给低风险、由用户自主选择的做法。
```

术语必须在第一次出现时随口翻译。例如：“印星多——用人话说，就是吸收信息、找依据、建框架这一路比较显眼”。不要要求客户先学会十神才读得懂自己。

## 二、首屏排版

客户看到的前两屏按下列顺序：

1. 标题和一行传统文化边界。
2. `老师傅先断`：连续、自然的口头总评。
3. `先核对这四件事`：三至五条短句。
4. `如果对不上，先查这里`：输入与推演误差说明。
5. `下面开始讲依据`：之后才出现四柱、旺衰、格局、用神和规则 ID。

首屏不要放密集表格，不要连续堆三个以上术语，不要让免责声明长过正文钩子。边界要清楚，但用一两句说完；完整边界放报告末尾。

后半部分可使用表格和规则编号，因为这部分的任务是证明、审计和供行内复核。每个大章先放一行人话小结，再进入术语。

## 三、判断质量

一条好的口头判断同时具备四个特征：

- **有对象**：说清是在熟悉领域、压力场景、合作关系还是商业交付中出现。
- **有机制**：解释“为什么会这样”，而不是只报性格形容词。
- **有两面**：同一结构的优势与代价同时出现。
- **可否证**：用户可以明确说“不，我长期不是这样”。

较差：

> 你很聪明，想得多，外冷内热，贵人运不错。

较好：

> 你不是学不会，而是学会以后不太愿意照搬。熟悉规则之前你会先观察；一旦看懂结构，就会开始挑问题、改方法。好处是能把复杂东西做成自己的体系，难处是标准提得太早，第一版常常出得比能力本身慢。

第二种说法仍然只是传统推演，必须在后文用盘面事实、规则、反证和现实核验支撑；不能因为它听起来具体就称为事实。

## 四、不准时怎么处理

若用户反馈核心总断明显不符：

1. 先原样记录不符项，不争辩、不诱导补充“其实也有一点”。
2. 区分排盘事实错误、输入口径差异、出生时刻误差、传统规则分歧和现实翻译过度。
3. 只有出生时间接近时辰交界时，才运行候选时辰对比；不得为追求吻合随意改时辰。
4. 无法稳定解释的结论降级为 `UNKNOWN`，并保留原判断与修订理由。
5. 单次“很准”或“不准”都不证明传统体系有效或无效，只能用于修订本次文本。

## 五、交付前口吻自检

- 开头是否像人在当面说话，而不是论文摘要？
- 前 600–1200 字内，客户能否复述“这张盘最主要的三件事”？
- 每条总断是否能在后文找到对应事实、术语解释、反证和核验问题？
- 有没有一句换到大多数人身上也成立、却没有进一步限定的万能话？
- 有没有为了钩子而写出恐吓、绝对化、具体灾祸或虚构经历？
- 如果客户说“不对”，报告是否给了真正可执行的排查路径？
