# 排盘输入契约

目标：在运行排盘前锁定日期、时间与历法口径，避免模型以默认假设悄悄补齐关键信息。

## 必需字段

| 字段 | 接受值 | 缺失或歧义时的处理 |
|---|---|---|
| 历法 | 当前运行时仅接受公历 | 农历必须先确认是否闰月，再用确定性工具转换并请用户确认 |
| 出生日期 | `YYYY-MM-DD` | 无法确认时停止 |
| 出生时间 | `00:00-23:59` 或时辰 | 未知时不得假造；可做相邻时辰候选比较 |
| 排盘性别参数 | 男 / 女 | 说明这是传统引擎参数；用户不愿提供则无法计算相关顺逆规则 |
| 出生地 | 城市、国家/地区 | 至少用于确定当地民用时间和时区；不能只凭城市名猜历史时区 |
| 时区 | IANA 名称或明确 UTC 偏移 | 不清楚时先确认；脚本只记录，不自动换算 |
| 换日口径 | `midnight` | 当前只支持午夜换日；其他流派口径标记 `UNSUPPORTED` |

## 当前实现边界

- `calc_chart.py` 把 `--date` 与 `--time HH:MM` 当作已经确认的当地民用时，不处理经纬度、真太阳时或夏令时；`--hour` 兼容旧调用并把分钟记为 `00`。
- 时区与出生地写入输出元数据，但不改变干支计算；它们用于保留输入证据和提醒复核。
- `lunar_python` 与 `iztro` 的版本必须写入 `_meta`。无法取得版本时写 `UNKNOWN`，不得省略。
- 农历转换、真太阳时、23:00 换日流派切换目前属于 `NOT_IMPLEMENTED`。

## 时辰索引

| index | 时辰 | 代表小时 |
|---:|---|---:|
| 0 | 早子 | 0 |
| 1 | 丑 | 2 |
| 2 | 寅 | 4 |
| 3 | 卯 | 6 |
| 4 | 辰 | 8 |
| 5 | 巳 | 10 |
| 6 | 午 | 12 |
| 7 | 未 | 14 |
| 8 | 申 | 16 |
| 9 | 酉 | 18 |
| 10 | 戌 | 20 |
| 11 | 亥 | 22 |
| 12 | 晚子 | 23 |

`--time`、`--hour` 与 `--time-index` 必须三选一。`--time` 严格为 `HH:MM`，小时范围为 0–23，分钟范围为 0–59；索引范围为 0–12。有分钟资料时必须用 `--time`，不能静默截断。

## 按需流年

- `--flow-year YYYY` 可重复，仅在用户明确要求具体年份时传入。
- 允许范围为出生年到出生后 109 年；未传入时 `八字.流年.状态` 必须是 `NOT_COMPUTED`。
- 流年输出只含干支、虚岁、大运归属、十神与可机械确认的合冲刑害/伏吟/岁运并临关系，不等于年度事件。
- 交运年份必须结合 `起运.起运公历` 与大运的 `交运公历` 细分，不能只按年份字段断定全年同运。
