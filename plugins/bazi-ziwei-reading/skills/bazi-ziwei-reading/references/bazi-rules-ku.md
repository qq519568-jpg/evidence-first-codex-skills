> **认识论边界**：下列标签只区分输入事实、规则来源与推演距离，不代表科学证据等级、统计显著性、准确率或真实世界概率。所有 A-E 内容仍属于传统命理解释。

## 一、内部推演分级（每条断语必须带标签）

| 层 | 等级 | 含义 |
|---|---|---|
| S 输入层 | S0–S3 | 用户输入与确定性排盘产物（干支/星曜/大运），S0=直接输入，S3=推算产物。**不得把模型推理伪装成 S 层** |
| A 推理层 | A | 结构性推理（旺衰/格局/喜忌的直接结论） |
| B | B | 常见范式推理（病型、组合论） |
| C | C | 经验性判断（性格延展、细节描绘） |
| D | D | 意象性发挥（比喻、画面感描写） |
| E | E | 待核对资料（歌诀、流派单说，须标注分歧） |

写作规范：A/B 层只能写成“在该传统规则下的主要判断”；C/D 层用"倾向/多主/常应"措辞；E 层必须标注"某派说法，待核对"。**任何层级都不得写成科学事实或必然结局。**

## 二、规则分层与冲突裁决

```
STRUCTURAL(结构层) > CORE(核心层) > SCHOOL(流派层) > HEURISTIC(经验层) > SUPPLEMENTAL(辅助符号层)
```

- **STRUCTURAL**：干支结构事实（得令/通根/刑冲合害的存在性），不可争。
- **CORE**：全派共识的推演规则（旺衰五档、用神取法）。
- **SCHOOL**：流派分歧（调候优先级、墓库吉凶、大运管法、真空假空）——**并列呈现，标注适用条件，不强行平均**。
- **HEURISTIC**：经验法则（应期铁则、病型断事主题），只作提示。
- **SUPPLEMENTAL**：神煞、纳音等辅助符号，**只作主题标签，不得对主判断做数值级增强**（禁用"放大/减力"式量化表述）。
- 跨层冲突：高层规则胜出；同层冲突：并列两种说法+各自条件。**严禁硬凑一致。**

## 三、经典病型速查（命局之病，C 级判断）

病型命中须逐条核对构成条件；病型命名只用于精确表述病机，**不自动改变喜忌方向**（喜忌仍由六维决定）。

| 病型 | 构成条件 | 断事主题 | 典型救应 |
|---|---|---|---|
| 枭神夺食 | 偏印强旺+食神被克（**特指偏印夺食神**，同性克力重；正印克伤官≠枭神夺食） | 表达受阻、才华压抑、思虑过度 | 财星制印；食伤得根 |
| 伤官见官 | 伤官正官并见（或岁运引动） | 口舌官非、与上级冲突；**金水伤官喜见官为例外**（调候优先） | 印制伤护官；财通关 |
| 比劫夺财 | 比劫旺+财星弱/被分 | 忌合伙借贷、防被夺（比肩分财轻、劫财夺财重） | 官杀制比劫；食伤泄比劫生财 |
| 财多身弱 | 财星当令成势+日主无根弱 | 机会多接不住、健康透支；**逢印比帮身运反发** | 印比帮身 |
| 印多为病 | 印星过旺+日主被滋而无力 | 依赖庇护、思虑内耗、行动力弱 | 食伤泄秀+财星破印 |
| 母多灭子 | 印星过旺至极、日主被淹（土多埋金/水多木漂/火多土焦/木多火塞/金多水浊） | 五行特定：怀才不遇、漂泊无根等 | 财星破印+食伤泄秀 |
| 官杀混杂 | 正官七杀并透/并现 | 女命感情波折、事业多头压力 | 去留（留有力者去无力者）；食神制杀留官 |
| 七杀无制 | 七杀当令透干+无制无化 | 身弱最凶，灾祸压力官非 | 食神制杀；印化杀；比劫抗杀 |
| 杀旺印弱 | 七杀旺+印透但无根被克 | 压力转嫁失败、贵人无力 | 补印之根 |
| 刃旺无制 | 羊刃/比劫极旺+无制无泄 | 刚暴易冲动、防血光 | 七杀制刃；食伤泄刃 |
| 贪合忘生 | 应生他神者被合去 | 受生之神失养、源头断流 | 破合或补受生之神根气 |
| 贪合忘克 | 应克他神者被合去 | 凶神无制（前提：合而不化） | 破合或另寻制神 |

## 四、经典成格范式（以药制病为贵——是成格，不是病）

**先决校验（P0）**：凡含印星的格局名（伤官佩印/食神配印/杀印相生/枭神夺食），**必须先答：印在此盘是喜是忌**。身弱印为用→佩印成立（印是药）；身旺印为忌→禁止用"佩印"之名，改称"身旺印重，印克食伤（按病型细分）"。

| 成格范式 | 成立前提 | 破格/变数 |
|---|---|---|
| 伤官佩印 | 身弱+伤官旺+印为用 | 身旺印为忌则不成立 |
| 食神制杀 | 食神有力+七杀当令（身弱杀旺） | **最怕枭神夺食破格** |
| 杀印相生 | 身弱杀旺+印化杀生身有力 | 身强杀旺不宜印化；印弱则杀攻身 |
| 羊刃驾杀 | 羊刃格+七杀有力制刃 | 杀无力制刃→退论"刃旺无制" |

## 五、变格四态状态机（NORMAL/FROM/ZHUANWANG/HUAGQI）

> 核心原则：从势/专旺/化气是**三个独立状态机**，成立条件与喜忌方向各不相同，**禁止用一个"喜忌翻转器"统一处理**。默认 `NORMAL`，不预设变格。

| 状态 | 含义 | 顺势方向 | 逆势方向 |
|---|---|---|---|
| NORMAL | 普通格局 | 按扶抑/格局正常取用 | — |
| FROM 从势 | 日主极弱，顺克泄耗之势 | 喜克泄耗 | 忌生扶 |
| ZHUANWANG 专旺 | 日主一方独旺，顺旺势 | 喜印比 | 忌财官食伤 |
| HUAGQI 化气 | 日主合而化，顺化神 | 喜化神五行 | 忌破化五行 |

**FROM 判据清单（逐条打勾）**：
1. 日主本气根是否存在？存在则查四类削弱：遭冲克/被合化/落空亡/处死绝——**"根被削弱"必须写具体落点，禁止凭感觉判从**。
2. 印比是否透干？透干有根→记"生扶有力"。
3. 克泄耗是否成势（占主导）？
4. 生扶是否极度微弱或全无？
- 裁决：判据1削弱+3通过+4通过→倾向从格（再分从财/从官杀/从儿/从势）；判据1根有力或判据2透干有根→倾向不从。仍不能决断→并列"身弱 vs 从格"双轨假设。
- 细分：从财（忌比劫印）、从官杀（忌印比）、从儿（忌印官）、从势（忌印比）。

**ZHUANWANG 专旺**：日主得令得地得势+克泄耗无根受制。**纯度要求极高——地支有一粒异类五行有根，多已破格退论普通身旺**；官杀有根有力为最大破格。五型：曲直(木)/炎上(火)/稼穑(土)/从革(金)/润下(水)，喜印比、忌官杀财（食伤两说，[SCHOOL]）。

**HUAGQI 化气**：①天干五合（日主与相邻干合）②化神当令 ③化神得地支三合/半合/会局之助 ④日主无强根 ⑤化神不受克。"逢龙则化"优先级极低，不作硬判据。化后喜忌以化神论（如甲己化土→喜土火、忌木水）。逢助日主本五行之根的岁运可能"还原"退复常格，[SCHOOL] 标注。

**裁决顺序**：先判 NORMAL → 有变格嫌疑先并列候选状态（如"专旺 vs 普通身旺"）各列条件与后果 → 选定后用**该状态自己的**规则取用 → 破格则明宣告"退论普通格局"并说明喜忌变化。

## 六、岁运应期铁则

1. **原局定事、岁运定时**——原局有象，岁运引动方应验。
2. **多重信号互证：≥2 个独立信号**。独立=来自不同结构层：①十神星动 ②宫位动 ③岁运引动 ④原局结构响应（伏吟/反吟/天克地冲/岁运并临）。同一层不同说法不算独立。
3. 分析顺序：原局为体→大运为纲→流年为目；**流年先与大运作用，再作用于原局**。岁运相冲、天克地冲、伏吟为当年最大变量。
4. 岁运并临=信号强化，非"加倍"，以喜忌定方向。
5. 大运管法分歧（[SCHOOL]）：干管前5年支管后5年 vs 干支一体十年统看——并列标注。
6. 墓库引动（P0）：先查库中所藏十神/库之喜忌/透藏/冲合与岁运承载，再分三支：①库开释放 ②破库折根 ③入墓受制。**禁止直接断"逢冲＝发财升职"**。
7. 流年冲柱主题：日柱=自身/婚姻，月柱=事业/父母，年柱=祖业/长辈，时柱=子女/晚年。

## 七、用神六维一致性检查（取用前必做）

扶抑 / 格局 / 调候 / 病药 / 通关 / 变格，六维分别独立评估：

- 各维各自给出：结论 + 依据 + 适用条件。
- 多维多一致 → 结论合并，喜忌清晰。
- 维间冲突 → **如实列出冲突与取舍理由，不强行统一**；路线级冲突（喜忌方向相反）时按竞争假设模板并列两条路线，用判别年份等用户经历裁决。

## 八、空亡与神煞定位（防乱用）

- **空亡**：非神煞，辅助修正项。用神/吉神落空→虚而不实；忌神/凶煞落空→反减凶。**不参与旺衰计算，不进主用神判断**，只作加减分与应期提示（填实/冲空之年）。
- **神煞**：《子平真诠》"星辰无关格局"——只作主题标签（桃花→人缘应期、驿马→流动变动、贵人→提携、华盖→艺术宗教缘），**不改变主框架结论**。
- **羊刃是结构性变量**（对应羊刃格），不入神煞表，按格局处理。
- 纳音：仅作意象补充，不参与旺衰。

## 九、竞争假设与不确定度模板

触发条件：从格嫌疑、专旺临界、调候与扶抑相反、关键合化翻转喜忌、墓库吉凶两派对立时。

模板：
```
主线假设 H1：…（依据：…；证据等级：…；适用条件：…）
竞争假设 H2：…（依据：…；证据等级：…；适用条件：…）
判别信号：H1 成立的判别年份/事件 = …；H2 成立的判别年份/事件 = …
当前取用：按 H1 为主，H2 备用；不确定度：高/中/低
```
多数盘只给单一主判断+不确定度标注，**不必每个盘都甩两个相反答案**。
