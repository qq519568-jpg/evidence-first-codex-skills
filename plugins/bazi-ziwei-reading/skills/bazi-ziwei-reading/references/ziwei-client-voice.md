# 紫微客户向“老师傅口吻”规范

本规范用于紫微详批的客户层表达。目标是先把命身主线、命财官迁联动和阶段主题讲成人话，再让客户往下查看宫位、星曜、四化、亮度和大限依据；不得靠单星标签、吉凶恐吓或万能性格话制造命中感。

## 一、开头抓什么

老师傅总断约 600–1200 个中文字，优先从三条线提炼三至五条 `紫断`：

1. **命身张力**：命宫说明传统框架中的内在驱动，身宫落宫说明后天更常投入的场域。两者要合看，不能把“身宫在迁移”直接写成必须离乡。
2. **命财官迁联动**：命宫、财帛、官禄、迁移四宫共同说明能力怎样被看见、承担责任和交换资源；不能由一颗星直接列职业或财富结局。
3. **四化落点**：禄、权、科、忌只作为关注与作用方向的修正，必须连同星曜、宫位、亮度和反向因素解释。
4. **当前大限主题**：只引用脚本已有大限区间；若当前虚岁需要另行推导，要声明算法和 `as_of` 年份。大限说明阶段课题更显眼，不代表具体事件必然发生。
5. **关系或压力机制**：证据不足就明确说“这条我不硬断”；空宫借对宫必须降低不确定度并说明借宫。

第一层不要从“紫微破军坐命”“廉贪化禄”“武杀守财帛”等行话起笔。可以先说：

> 你这张盘最鲜明的不是单纯求稳或单纯爱变，而是外面看起来能接住局面，里面一旦认定旧结构失效，就会想把事情重新做一遍。

然后再分别讲它在熟悉领域、公开合作、职业责任、金钱交换或关系压力中的表现。每条必须同时写好处、代价、适用场景和一个能被用户否认的核验点。

## 二、后文怎样证明

每条总断标为 `紫断 1`、`紫断 2`……，后文采用同一证据卡：

```text
对应紫断：紫断 2
人话小结：这一组宫位对现实机制意味着什么。
盘面事实：宫位、宫干支、主星组合、亮度、四化、辅煞与大限原值。
行话解释：命身、三方四正、四化或借宫规则怎样形成候选解释。
反证与限制：不支持因素、空宫/借宫降级、亮度与辅煞修正、未计算字段。
现实核验：给一个可以明确回答“不符合”的问题。
现实建议：低风险、非决定性做法。
规则 ID 与不确定度：集中放在证据层，不塞满口头总评。
```

术语第一次出现必须随口翻译。例如：“破军化权——用人话说，是遇到旧办法失效时，更愿意接过改造权，而不是只做局部修补”。这仍是传统象征，不是用户真实经历。

## 三、紫微专属禁区

- 不写“命带魁钺，一生贵人不断”“化禄必发财”“化忌必有灾”。
- 不把杀破狼、机月同梁、紫破、廉贪等组合名直接当成职业、阶层或命运结论。
- 不把星曜亮度当固定分数；引擎原值不熟悉时原样保留，不擅自扩写。
- 不把空宫直接说成“没有婚姻、没有事业”；借对宫是传统推演，必须点名对宫并降低确定度。
- 不从大限手排流年宫位或流年四化；脚本为 `NOT_COMPUTED` 就停止逐年断事。
- 不把宫名当真人事实：田宅大限不等于一定买房，迁移身宫不等于一定移民，夫妻宫结构不等于真实婚史。

## 四、不符时先查什么

若多数紫断长期不符：

1. 复核公历/农历、闰月、出生时辰序号、男/女排盘参数和换日口径。
2. 检查命宫、身宫、十二宫星曜和四化是否来自本次 JSON，而不是旧盘或手排记忆。
3. 区分直接宫位事实、三方四正组合、空宫借宫和现实翻译；越往后不确定度越高。
4. 只有出生时间接近时辰边界时才比较候选盘，不为追求吻合随意换时辰。
5. 若盘面事实无误而现实机制仍不符，把相关紫断降级为 `UNKNOWN`，保留不符记录。

## 五、首屏自检

- 客户是否先听懂“内在驱动、外在落点、事业/财务机制和阶段课题”，而不是先学十二宫？
- 三至五条紫断是否分别连接至少两项盘面事实，而非单星直断？
- 是否给了三至五个可否证核验点和真正的误差入口？
- 是否把已知用户背景标成非盲测信息污染，没有反写成命盘命中？
- 是否明确紫微流年状态，杜绝模型手排？
